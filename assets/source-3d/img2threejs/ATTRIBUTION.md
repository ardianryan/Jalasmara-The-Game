# Memory slab source and limits

The reference crops come exclusively from Jalasmara's own original `ocean-props-atlas.png`, not from the upstream project's demo gallery or a third-party game. `origin.json` records the crop coordinates and source hash.

The offline tool uses img2threejs at commit `0c0c49bc168e648dbaf9c8c080474de0b3a941b6`, under Apache-2.0; the upstream license accompanies the adapter and runtime GLB. Three.js and GLTFExporter run only in the offline build environment. The GLB and camera renders are generated from this project's authored spec through the official factory.

This is a low-poly blockout with actual frame thickness, frame opening, and an inset backing insert. A single image does not determine the rear or true depth. The render is suitable as subdued background structure behind the original tablet sprite. It is not a full eight-pass reconstruction approval or an authentic cultural artifact.
