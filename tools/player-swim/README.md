# Swim pose authoring

`python3 tools/player-swim/build_swim_atlas.py` rebuilds four compact swim strips from the project's existing modular base portraits. It selects the three distinct poses in row two, downsamples each 418 px source cell to 112 px, applies one 28-color palette across the strip, removes isolated edge specks, and draws a seven-pixel-wide cyan diving visor at reviewed face anchors. Eight cycle frames reuse those three source poses, with two-pixel bends confined to the free fin tips. The leg roots, torso, face and modular gear are unchanged. The generator writes a source/output SHA-256 manifest beside the PNGs. Pillow is an offline authoring dependency; Godot loads only the generated PNGs. Run `python3 tools/player-swim/test_swim_atlas.py` to check the alpha, frame and provenance contract.

The animation phase is driven by actual swim displacement in `CharacterVisual.gd`. Eight frames still come from only three original poses; they are one facing and do not constitute eight-way underwater character art. Keep the original `*-base-v1.png` sources; the generated strips inherit the project's artwork terms. Review the cycle at 1:1 and in motion in a native gameplay capture before accepting a regenerated atlas. The face anchors and fin flex boundary are authored for these four exact portraits; revise them if the source poses change.
