# Changelog

This file records named project versions. The owner has asked to keep the project at **0.1.0** during early development; future version headings will be added only when requested. Day-to-day progress remains in [development status](docs/development-status.md) and [review reports](docs/reviews/).

## [0.1.0] — 2026-11-10

Initial documented prototype baseline, not a claim of feature completion or a new semantic-version release on this date.

### Available in the current staging build

- Browser-playable Godot game with a three-quarter-view land world, forest route, and underwater exploration.
- Nala's daily, explorer, and diving clothing with modular equipment and a dock changing interaction.
- Resident routines, village/home interactions, SmaraPedia, Kedai Waras, and a server-owned 36-minute active-time day.
- React/Vite host, Fastify API, MongoDB progress, Redis sessions, and Gitea CI with a separately verified staging activation.
- Offline WorldKit map drafts and pixel-asset preparation tools, with upstream attribution.

### Known limits

- Natural walking/contact across every direction and terrain is not accepted; the experimental physical-gait pilot remains off.
- Visual finishing, HUD readability in every setting, and long-form playtesting remain in progress.
- Physical Windows and Samsung S23 performance measurements are pending.
- No independent security audit has been completed.

The source, asset hashes, public smoke results, and rollback identity for this baseline are in the [staging report](docs/reviews/staging-main-446abf4-2026-11-10.md).
