# Phase 1 cinematic direction

This document maps the owner's screenplay to the current Godot 4.7.2 game. The Indonesian dialogue lives in `client-godot/scripts/PhaseOneCutscenes.gd`; `CutsceneFrame.gd` presents letterbox framing, warm/plum/teal/deep color cues, shot labels, a twelve-frame boss cut-in, procedural fog/rays/bubbles/quake/memory motes/hologram lines, and a touch-sized skip button over the live game world. `Main.gd` connects the beats to actual play. Gameplay, rewards, calendar time, questions, and boss victory remain server-owned.

`user://phase-one-cutscenes.cfg` stores only cosmetic seen flags keyed by authenticated player ID. It does not grant rewards, advance the calendar, or change server progress. A player on another device may replay a cinematic; this is preferable to treating local playback as authoritative. Completing or skipping a sequence marks its local flag. A failed local save still suppresses replay in the current session.

## Art and acceptance limits

The follow-up art pass adds three original, lightly panned pixel-art backgrounds for the prologue, Tamansari boss and epilogue; [provenance and hashes](../assets/cinematic-backgrounds-v1.md) record the sources. Other shots still use the live world, existing portraits, Gajah Mina motion atlas, dialogue, color overlays, procedural motifs, and project audio. It **does not yet** animate the screenplay's boat backflip, unique five-child ensemble, capsule crowd, literal pipe fracture, full 3D map projection, or large-scale memory-particle rain as bespoke cutscene assets. Those are separate art/animation tasks. Before claiming the visual screenplay complete, capture a new-player playthrough, a day-2/day-3 progression, and all six boss resonances in a real browser; review the 667×375 and 844×390 layouts, audio continuity, skip behavior, and FPS on Windows and Samsung S23.

The screenwriter's Phaser shader names are directions, not runtime requirements: Godot's existing weather/underwater rendering and the cutscene color overlay provide the current cues. There is no Phaser migration or second renderer.
