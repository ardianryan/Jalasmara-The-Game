# Phase 1 cinematic backgrounds, v1

Three original backgrounds were generated for this project with the built-in image generation tool on 14 November 2026. Ardian Ryan supplied the Phase 1 screenplay and visual direction. These are project art, not copied from reference games or moodboards. They are used in Godot cutscenes behind the existing animated Gajah Mina sprite.

The art brief requested a 16:9 landscape, crisp colorful pixel-art diorama, warm tropical Nusantara wood and teal water, and no text or logos. The prologue prompt described Bandar Hujung before the Kabut Nir-Aksara with a distant industrial plant. The Tamansari prompt described an underwater temple arena with coral, beams of teal light, corroded industrial pipes and purple acid, with no creature or character. The first generation nevertheless included a creature; a second image edit removed it and rebuilt the right-hand architecture. The epilogue prompt described Nala's wooden veranda, hydroponic garden, lanterns, calm sea and dusk sky. The source PNGs are preserved; ImageMagick point filtering resized each to 960×540 and stripped metadata for runtime. No external sprite pack or tool repository was included.
