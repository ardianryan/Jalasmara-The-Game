# Timber-house detail candidate, 15 November 2026

The owner asked for the coastal buildings to reach the cozy pixel-art moodboard. This isolated candidate adds deliberate roof courses, porch joinery and side-wall amber windows to six existing timber houses. The first render showed only a faint roof change; side-wall windows were added because the camera exposes that long blank wall. The [matched Griya capture](../visual/moodboard-house-detail-before-after-20261115.png) shows the final native before/after at 844×390. The second 667×375 capture was inspected locally. Both show a clearer house volume without changing its roof silhouette or the dock-aligned footprint. **This is a bounded improvement, not full moodboard parity.** The houses still need authored wall/roof pixel clusters, set dressing and browser/device review.

`ShelterArchitecture3D.add_house_details()` is opt-in. It uses the already selected local building frame and existing wood, bamboo and amber materials. For each timber house it creates one roof-course mesh and 19 shallow boxes. The existing static batch reduces the scene to 57 material batches both before and after; no new light, shader, collision body, support surface or per-frame work is introduced. Metal office, director RV, balai and metal-roof workshop are excluded. The connector call in `LandWorld3D._house_parts()` is intentionally left to the integrator, who owns that shared renderer; the render fixture subclasses it only for this isolated comparison.

Validation on Godot 4.7.2 Compatibility, Apple M2 native renderer:

- `house-facade-detail.gd` passed for three timber variants and four exclusions, roof bounds and the exact geometry budget. Its first version failed because the test used a strict `<75` bound for a sill exactly at 75; the test bound was corrected, with no production geometry change.
- Native `moodboard-house-detail-render.gd` produced matched 844×390 and 667×375 before/after frames. Both were inspected; amber side windows are visible and the roof bands stay attached. Its first native launch stalled before script output and was interrupted. The repeated run completed; the final render log contains no `ERROR` or `SCRIPT ERROR`.
- `git diff --check` passed. The render report counts ten existing houses and 57 static material batches in all four frames; six houses receive the new timber detail.
