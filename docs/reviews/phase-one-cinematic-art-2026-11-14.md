# Phase 1 cinematic art follow-up — 14 November 2026

The owner asked whether tools could be used to make the Phase 1 cutscenes visually stronger. This package on `work/phase1-cinematic-art-20261114` adds three original imagegen backgrounds to the existing Godot `CutsceneFrame`: warm Bandar Hujung, an empty submerged Tamansari arena, and the dusk Griya Sasmita veranda. A gentle camera drift is disabled when reduced motion is on. The boss still uses the separately animated existing Gajah Mina atlas in front of the empty arena. Other shots retain the live world. No story progression, boss rules, rewards, physics, server state or audio composition changed.

The first Tamansari generation accidentally included a static creature; the final image was edited to remove it. Source images, prompts, method and SHA-256 hashes are in [cinematic asset provenance](../assets/cinematic-backgrounds-v1.md). The tool actually used was built-in OpenAI imagegen, followed by ImageMagick point-filter resize to 960×540; no Sprite AI, Cinetic, third-party gallery art or new runtime library was used. The output is project art; external reference images were not distributed.

Native Godot 4.7.2 captures were reviewed at 960×540, 844×390 and 667×375. Curated evidence: [prologue](../visual/phase1-cinematic-prologue-20261114.png) (`5233103659dd08621d47632786a9cc3c8e3049a6d01d9040d5cdcafbaaf71205`), [boss at 667×375](../visual/phase1-cinematic-boss-20261114.png) (`87b3660945ad9aa3b179a80f49638a1b5dd5068abedecdab5b550a205261b1c7`) and [epilogue](../visual/phase1-cinematic-epilogue-20261114.png) (`ec01bde871216de5901cd63ace4abd04e0b67f549209b777f13a0496aafe7106`). These are native component captures, not live browser progression or phone FPS evidence. The render fixture is `scripts/tests/cinematic-art-render.gd`.
