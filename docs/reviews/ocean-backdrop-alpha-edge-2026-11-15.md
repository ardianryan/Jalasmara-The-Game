# Ocean backdrop alpha edge, 15 November 2026

The existing ocean atmosphere atlas uses a soft transparency fringe. `OceanBackdrop.gd` previously discarded only texels below alpha 0.2, then rendered every surviving texel as opaque. That let semi-transparent fringe pixels become solid cards around distant karst forms, weakening the crisp pixel silhouette. This package moves the discard threshold to 0.5. It changes no atlas bytes, world geometry, collider, progression, HUD, PCK transport or gameplay rule.

The existing 1536×1024 project atlas has about 55.3% pixels at alpha 0–50, 1.4% at 51–127, 1.7% at 128–200, and 41.6% at 201–254. The new threshold removes the low-alpha fringe while retaining the fully painted rock. The [new native reef frame](../visual/ocean-alpha-cut-native-20261115.png) shows a firmer left karst outline than the [previous frame](../visual/ocean-pixel-refinement-20261115.png). Both are 1440×810 Godot 4.7.2 Compatibility captures on Apple M2; animated objects can differ by frame time, so this is a visual comparison, not a pixel-perfect image-diff test.
