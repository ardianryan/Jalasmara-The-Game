# Ocean backdrop alpha edge, 15 November 2026

The existing ocean atmosphere atlas uses a soft transparency fringe. `OceanBackdrop.gd` previously discarded only texels below alpha 0.2, then rendered every surviving texel as opaque. That let semi-transparent fringe pixels become solid cards around distant karst forms, weakening the crisp pixel silhouette. This package moves the discard threshold to 0.5. It changes no atlas bytes, world geometry, collider, progression, HUD, PCK transport or gameplay rule.

The existing 1536×1024 project atlas has about 55.3% pixels at alpha 0–50, 1.4% at 51–127, 1.7% at 128–200, and 41.6% at 201–254. The new threshold removes the low-alpha fringe while retaining the fully painted rock. The [new native reef frame](../visual/ocean-alpha-cut-native-20261115.png) shows a firmer left karst outline than the [previous frame](../visual/ocean-pixel-refinement-20261115.png). Both are 1440×810 Godot 4.7.2 Compatibility captures on Apple M2; animated objects can differ by frame time, so this is a visual comparison, not a pixel-perfect image-diff test. The new PNG SHA-256 is `fa7a22c0fd7bbab456b94146eaa12e7e2210d2b02be19cb97dde093e363e28b2`.

Verification: focused `ocean-backdrop.gd` passed alpha-gutter, three parallax layers, reduced motion and unchanged collision/progression; `ocean-platform06-render.gd` produced six native full-scene captures with lamp on/off, two facings and camera seams; `npm run check:world`, `npm run typecheck` and `npm run build` passed without `SCRIPT ERROR` or Godot `ERROR` in their logs. This is **one edge-cleanup step, not full moodboard parity**. The center water remains broad and flat, and the source atlas retains a painterly shading structure. A local-only 48/32/24-color downsampling experiment was rejected after inspection: harder blocks did not create the intended authored pixel clusters. Its temporary files were removed and no derivative art entered the repository. The next visual work needs scene composition and source-level pixel editing across coast, ocean, structures and characters, with Windows/S23 moving-frame review and frame-time comparison. Asset source and license remain the existing project atlas; tools used were Godot 4.7.2, Python/Pillow for inspection only and Node build checks.
