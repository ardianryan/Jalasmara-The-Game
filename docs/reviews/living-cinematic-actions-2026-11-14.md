# Living cinematic actions — 14 November 2026

## Candidate and scope

The owner asked for immediate, lightweight pixel/code-authored motion that makes gameplay and cutscenes feel less static. Isolated branch `work/living-gameplay-20261114` adds a separate Godot action layer for three Phase 1 beats: Nala's oared sampan crosses Bandar Hujung on prologue shot 6, the existing Tamansari pipe shows a fracture and dispersing fragments at the 3/6 boss transition, and the epilogue's prasasti projects a moving depth route. The layer sits above the animated environment plate and below dialogue, skip controls and Gajah Mina. Reduced-motion mode draws its resting pose. No server state, combat, calendar, rewards, dialogue or source paintings change. The work is source-local until an exact GitHub Actions delivery bundle is verified and activated; the previously released staging source remains `6d2873240063275ba5c251ee18155dd002c8e21f`.

The [plan](../plans/10-living-cinematic-actions.md) records the acceptance scope. Original source backgrounds remain at SHA-256 `3e144948d282e0a2b730ee52c7e3b52fb70aa881fd0c1adcfb11a110a8acba1b` (prologue), `65d5dbffbe06faf130b69d368de2b09e6c0f378477943d559c95ba586cf501bb` (Tamansari), and `bcfffa8774cb0434a8a06c39ea8bbe20ba380f33f4868bea1968563e149871c0` (epilogue). New shapes and timing are project-authored GDScript, not imported or generated sprites. Godot 4.7.2 Compatibility was the only runtime tool used. ImageMagick compressed the three original Godot screenshots for documentation; it did not change game assets. PixelHand was available offline but not used; Cinetic, SpookyGhost and Crivo were not run. [Konado](https://github.com/godothub/konado) was reviewed as a Godot dialogue toolkit and is a reference only, with no code or license bundled here.
