# Carried-pivot stair resume model

The unchanged `a7e7ace` full16 attempt completed six normal cases, then rejected ridge ascent at original drop 8.90117. RIGHT, just released from the real 128 tread, remained the limiting leg after LEFT's unfinished ascent resumed through the old D23 curve to 144. RIGHT's horizontal reach was still valid (19.81373 against 27.97782); the coupled timing left insufficient vertical reach. Merely keeping body height at 128 would still fail. No body/drop/limb bound changes are proposed.

At the actual pause LEFT uses the original NORTH mask, identity sole plane and carried pivot `(-.9677967,+.9677967,-.0377456)`, then can switch to NW while airborne. A fresh C0-only path cannot silently replace that state. `tools/player-gait/model_stair_resume_carry.py` preserves the real raw start 124.0308, actual original source masks, frozen 144 target, initial ankle and linear pivot decay. Its candidate riser knots account conservatively for the initial pivot's horizontal leading extent and negative vertical offset. The quarter duration is derived from original XYZ arc, existing 3-unit sinusoidal lift, pivot derivative and support-stitch reserve, not a new literal gait constant.

The current-mask candidate derives D13.25 from arc 35.5871654. It models both holding NORTH and the earliest original-full-mask-clear NORTH→NW handover, adding the exact ankle-offset difference to C then decaying it across the remaining accepted distance. The latter model never forces a view switch through terrain. For this captured handover the correction derivative after switching is smaller than the initial `|C|/D`; that is a conditional vector calculation, not a guarantee for arbitrary views. Both original body-leg annuli and the common maximum 8-pixel pelvis drop are evaluated throughout the path.

An initial model mistakenly kept the free-foot `.02` floor stitch at the contact endpoint. Correcting contact to the exact original target exposed a real dense-step discontinuity: the old constant stitch fails the unchanged ankle guard at a 0.001325-unit last accepted increment. That failed comparison is retained. No ultra-small step is waived because normal frame rates pass.

The candidate taper is `4*.02*u*(1-u)`: zero at the actual start/end, the same `.02` peak, and derivative at most `.08/D`. Its floor term compensates only the actual initial negative C component as it decays; the additional `|C.z|/D` reserve is explicit. This prevents lowering the original geometry through the floor without creating another tread or changing the fixed contact. Free-foot clearance approaches zero continuously at true contact; it does **not** claim a universal strict `.02` airborne margin. Existing runtime geometry/ankle guards remain authoritative.

The model checks seven independent phase schedules: dense 10,000 increments, logarithmic endpoint increments down to `D*1e-9`, frozen 30/60/120/2000 Hz motion and the original observed accepted-distance schedule. The tapered current-mask/N→NW candidate has zero ankle-guard violations on all seven, maximum observed ratio about 4.0721, maximum drop 3.4511 pixels, positive inner slack, no horizontal rejection and exact terminal contact. The endpoint asymptotic ankle derivative is about .7087 per accepted unit, eliminating the old constant jump. Terminal NORTH and NW original full masks both have zero minimum floor gap at the unchanged 144 target.

The initial endpoint test had a duplicate phase producing NaN. The final model deduplicates phases, asserts strictly positive increments and serializes with nonfinite values forbidden. It exits nonzero if the selected finite geometry/ankle/annuli/contact checks fail, and separately requires preservation of the old constant-stitch counterexample.

A follow-up locates every actual center-floor riser crossing on the proposed raw curve and checks both one-sided limits at `u±1e-9`. At both remaining ridge risers the un-clamped path already exceeds the new floor plus taper and pivot compensation, so the floor branch is inactive across the height discontinuity. This closes that captured center-clamp jump concern; it does not convert the finite full-corner/view checks into a universal continuum proof.

This is a frozen original-foot, fixed-view/body-family CPU model, not runtime, continuum-full-mask, next-step, DOWN, full16, current32, native, cadence or performance acceptance. The pilot remains OFF; no runtime port is included in this checkpoint.

The subsequent isolated runtime candidate tries this mode only for unfinished ascending stair resumes while the actor is still on the connector. The helper also requires real increasing from/to tread membership, an identity sole plane, finite source basis/pivot, an already clear original current mask, and a current/adjacent foot view whose original vertical ankle offset matches the body-view foot. Missing or unsupported geometry keeps its explicitly labelled old pilot path; none is accepted by bypassing the existing mesh/anatomy guards. Actual C is retained throughout; it is never zeroed to satisfy the old fresh-path condition.

The helper adds the conservative initial-C leading extent and vertical offset to real riser waypoints, reserves `|C|+4*.02+|C.z|` in its derived quarter duration, and labels future source-view operations outside its certificate. The planner applies the continuous taper and decaying initial-C floor compensation only to this new carried-resume mode. Fresh paths retain their previous behavior, including their unresolved tiny-step contact-stitch limitation; this bounded change does not claim a global gait repair. Body/support policy, source pixels, contact counters, frozen target, input/root coordinates, reach/drop, actual ankle and full-mask guards are unchanged.
