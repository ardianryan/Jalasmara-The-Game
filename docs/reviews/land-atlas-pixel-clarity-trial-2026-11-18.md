# Land atlas pixel-clarity trial — 18 November 2026

Status: diagnostic only. Branch `work/world-pixel-clarity-20261118` began at `e6c9898`. The tested shader and temporary render fixture were reverted; no land material, atlas, render budget, or gameplay code is proposed for merge.

The land renderer already uses a 480×270 pixel budget with nearest display filtering. Its grass, dirt, sand and limestone microtiles are 32×32 images loaded without mipmaps and sampled nearest. The fallback project material atlas is 1536×1024, six 512×512 cells; each cell repeats over 150 world units, so high-frequency details can be skipped in the small render viewport. The source atlas was generated for this project with imagegen on 8 November 2026, per [modular land art](../assets/modular-land-art.md). This trial added no external asset or dependency.

I tested a single change in `LandMaterials.gd`: quantize the existing atlas UV to 48 or 24 cells per repeat before its existing texture lookup. The latter is the stronger [667×375 baseline](../visual/land-atlas-clarity-trial-20261118/hub-baseline-667x375.png) / [candidate](../visual/land-atlas-clarity-trial-20261118/hub-quantized-667x375.png) and [844×390 baseline](../visual/land-atlas-clarity-trial-20261118/hub-baseline-844x390.png) / [candidate](../visual/land-atlas-clarity-trial-20261118/hub-quantized-844x390.png). All four are original native Godot captures from the same camera, area, daylight and source checkout. The other four paired forest frames were inspected locally. They are diagnostic images, not release art.

At actual display size the 48-cell variant barely changes the hub (mean absolute RGB difference 0.093/255, 2.0% of pixels differ by more than two levels). The 24-cell variant changes 0.122/255 and 3.0% of hub pixels at 667×375; forest changes 0.023/255 and 0.54%. The 844×390 results are similarly small (hub 0.127/255, forest 0.019/255). Wood/roof detail is not materially clearer, while grass and stone remain unaffected because they use their own microtiles. Quantizing this atlas does not solve the user's blurry/comfy pixel-art gap, so the candidate was rejected.

Godot 4.7.2 Compatibility performed a clean second import and both native A/B runs without `SCRIPT ERROR` or `ERROR`. The first fresh import briefly logged missing fontdata while importing; the second was clean. Source inspection, ImageMagick 7.1.2-31, Pillow and Godot were the tools actually used. No browser or physical Windows/Samsung S23 benchmark was run, and dusk was not recaptured because both daylight candidates failed visual review. Full combined checks are unnecessary for a reverted runtime trial.
