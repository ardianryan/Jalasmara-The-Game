# Phase 1 cinematic motion — 14 November 2026

The owner asked for the Phase 1 cutscenes to look alive instead of displaying static illustrations, and asked whether the previously installed Cinetic tool was being used. Source commit `58a4b755405a01f3cd90a0aa8183a84ce287f20f` on isolated branch `work/cinematic-motion-20261114` adds a moving image plane to the existing Godot `CutsceneFrame`. This is a local candidate at the time of this report; it has not passed GitHub CI or been activated on staging. Active staging remains source `f3f0ab4` with CI PCK `b73dbf7d82ce79e821d74e04643465a87a7f4ef9a3160743f764703fa573ce0c` and image `9dfde26231b5`.

The original 960×540 pixel-art paintings and their SHA-256 hashes in [provenance](../assets/cinematic-backgrounds-v1.md) are unchanged. A new Godot CanvasItem shader samples them through independently masked planes: ripples and reflected light on Bandar Hujung's water, a slow factory plume, underwater caustics and edge kelp at Tamansari, and sea shimmer, veranda foliage and lantern light at Griya Sasmita. Existing ambient motes are now visible over the paintings. Gajah Mina remains a separate animated atlas above the Tamansari plate. The frame still pans gently, but houses and temple masonry remain anchored. Reduced-motion mode hides the animated texture plane and stops the drift. No story gates, dialogue, audio, combat, rewards, physics, or server state changed.

The renderer is **Godot 4.7.2 Compatibility**, already the game runtime. Cinetic was inspected at local pin `f4bbfc844877891fe92279d47b7874fb44d485ae` and its [authoring README](../../tools/cinetic/README.md)/skill; it is suitable for a separately rendered trailer or noninteractive film, not for the live, skippable Godot dialogue frame. Its full Python/Chromium/renderer stack has not been validated here, and Remotion's commercial terms still need review. No Cinetic render or dependency is included. No new raster asset or third-party sprite was added; the only new image files are original Godot screenshots for development evidence.
