# Cutscene lighting continuity candidate — 18 November 2026

Status: isolated source candidate on `work/cutscene-light-continuity-20261118`, based on local `main` `5c57ee7`. It has not been integrated, pushed, or staged. The two original moodboard images were used only for comparison; no outside art entered the game.

Land cutscenes previously applied only a fixed warm, plum, teal or deep shade. `CutsceneFrame.gd` now reads `EnvironmentState.snapshot()` each visible frame, using the already smoothed `presentedDaylight` and `presentedMinuteOfDay` plus cloud coverage. It uses the same daylight normalization and dusk window as `LandWorld3D.lighting_palette`. A bounded environmental tint colors the painted land plate, a subtle foreground actor modulation follows daylight, and the living plate's lantern response strengthens at night. The story's plum and deep tints remain dominant; underwater scenes retain their existing fixed tint. The source painting and UI text remain unchanged.

The final dialogue callback in `Main.gd` now asks `CutsceneFrame` to fade its whole layer to the visible game world in 340 ms. The skip target is disabled and loses focus during exit. A new cutscene cancels the exit, restores full opacity and re-enables the target. Reduced-motion mode closes immediately, including when enabled during an exit. This is a presentation transition; server time, story progression, rewards, physics and audio calls are untouched.
