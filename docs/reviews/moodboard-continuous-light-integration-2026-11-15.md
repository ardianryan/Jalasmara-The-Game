# Continuous moodboard lighting integration — 15 November 2026

The owner requires morning, day, dusk and night to change through lighting and color rather than a frame cut. This package integrates the [land shader and daylight curve](moodboard-land-shader-continuity-2026-11-15.md), [clock-correction presentation values](moodboard-clock-jump-visual-2026-11-15.md), and [underwater light shafts](moodboard-ocean-light-2026-11-15.md). The same local main also contains [bounded terrain facets](moodboard-terrain-edges-2026-11-15.md) and [timber-house detail](moodboard-house-detail-2026-11-15.md). These are bounded improvements; full moodboard parity remains open.

The authoritative 36-minute calendar, phase-one gameplay, collision, boss rules and API did not change. `EnvironmentState` supplies separate presented time/daylight values to the existing land, water, lamp, rock, actor and effects paths. First sync starts at the correct value; later shift/heartbeat corrections approach it smoothly, including the midnight wrap. A new scene initializes its tint from the current presented state. The land grade replaces the existing display shader; ocean shafts use the existing water plane, with no added draw pass. Both keep nearest-neighbor pixel silhouettes. Low-performance and reduced-motion behavior are retained.
