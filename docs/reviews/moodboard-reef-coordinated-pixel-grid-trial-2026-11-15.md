# Reef atlas pixel-grid trial — rejected at gameplay scale

Date: 15 November 2026. Isolated branch: `work/reef-composition-20261115`, base `e0618550f9ba23d4cb6ba40ea24d336a1733ca7f`. This is a visual research result, **not a runtime change or staging release**.

The previous coral-only replacements did not address the painterly limestone beside crisp Nala and fish. I therefore tested a coordinated source-art treatment of all three original project atlases used by the underwater scene: ocean atmosphere (1536×1024), terrain (1536×1024), and coral clusters (2172×724). The originals remained unchanged. Candidate textures kept the atlas cell layout and hard alpha, and were substituted only in `OceanBackdrop`, `TerrainGeometry`, and the 2D `OceanScenery` fallback. No geometry, collision, fish, oxygen, progression, or lighting parameters changed.

Two candidates were rendered against the same base frame. The first used the installed Image-to-Pixel 3.2.0 CPU adapter and its 18-color Jalasmara palette at 768×512 atmosphere/terrain and 726×242 coral. Its hard grid was obvious, but the passage limestone became flat and speckled, losing carved depth. The second used Pillow 11.3 nearest downsampling and 48 adaptive colors per atlas at the same dimensions. It preserved more limestone form but looked very similar to the original in the reef and made the cave foreground patchier. The same-camera [667×375 comparison](../visual/reef-pixel-grid-review-667x375-20261115.png) (SHA-256 `1e97eefa3004b3fce95cdd6fee4c568ccd07cab31fbc96ea5a84bf558774d029`, 619,975 bytes) and [844×390 comparison](../visual/reef-pixel-grid-review-844x390-20261115.png) (SHA-256 `713074741d242c412d6a70a77e3af53b7e65ce652744706702e527f29419c856`, 674,684 bytes) retain baseline and 48-color frames. The 18-color frames were reviewed locally in the isolated worktree and rejected without promotion.

The project Godot 4.7.2 Compatibility native fixture `scripts/tests/moodboard-ocean-shafts-render.gd` passed all four captures for baseline, 18-color and 48-color variants at both sizes, printing `OCEAN SHAFT RENDER PASS` with no `SCRIPT ERROR` or `ERROR`. Source fixture oxygen stayed 77 and coins 700. The first editor import showed transient missing font-cache errors; a second import completed without errors. Image-to-Pixel's three adapter tests passed. A fourth mixed-palette run hung before capture and was terminated; it supplies no evidence. These are native Apple M2 still frames, not moving gameplay or Windows/Samsung S23 frame-time results.

**Decision:** both atlas-wide transformations were rejected. Their temporary PNGs, import files and runtime path edits are not part of this branch. The original project-generated atlases, their provenance and artwork license remain authoritative. The installed Image-to-Pixel tool is MIT with its existing upstream notices; Pillow was used only for disposable visual analysis. No external moodboard pixels or new game dependency were introduced.

The next reef pass should change authored **silhouette and depth composition** before palette conversion: shape the rear limestone into readable ledges and openings, then place a limited number of coral clusters to support those forms while leaving the swim lane and six existing encounter points clear. Match the surrounding texture grid to that composition in a new same-camera A/B and inspect motion and actual GPU pacing before staging. A global quantizer alone is not an acceptable shortcut to moodboard parity.
