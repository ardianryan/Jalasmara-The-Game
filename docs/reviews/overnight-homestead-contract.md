# Overnight: jahe dan keramba otoritatif

Kandidat dari main `d070a7b`, worktree `Jalasmara-overnight-village`. Pengguna meminta seluruh delapan pekerjaan dilanjutkan malam ini; root membagi lane desa/budidaya, karakter, website, serta integrasi. Paket ini tidak mengubah image rilis atau `app.ts`.

Kontrak existing `crop`, `market`, `gardenServing`, permit, dua petak, kalender36menit dan endpoint `/homestead/action` dipertahankan. Definisi menambah `crops` (kangkung/jahe) serta `servings` (kangkung/jahe/ikan_seruni). Jahe membutuhkan4hari terawat, biaya bibit30, hasil3, bonus penyajian12. Kangkung tidak diubah. `gardenItemId` pada `/kedai/serve` opsional; jika tidak dikirim memakai kangkung tanpa menambah field default pada fingerprint receipt lama.

Keramba memakai stok fisik `liveCatch.reef_seruni`, bukan fragmen pengetahuan. Tangkapan Bintang3 `ekosistem`/`netralisasi` yang memang dirender sebagai reef_seruni existing menambah stok hidup pada sesi dive; hanya ekstraksi berhasil memindahkannya ke rumah. Catch target/answered guard dan receipt extract mencegah duplikasi. Dua induk diperlukan setelah izin kebun dan siklus cerita2. Pakan2koin sekali perhari;2pergantian hari yang diberi pakan menghasilkan1ikan, maksimal5hasil belum dipanen. Hari tanpa pakan tidak tumbuh. Panen memberi `produce.ikan_seruni`; titipkan ke kedai, lalu penyajian sah menghabiskan stok dengan bonus10. Fragmen ilmu untuk resep tetap wajib.

State tambahan dinormalisasi untuk save lama tanpa mengubah stok existing atau memberi induk/bibit gratis. `dailyUser` menyimpan migrasi sehingga refresh tidak membangun state berbeda. Calendar settlement memeriksa `lastSettledDay` setiap pen sebelum menambah progres. Transaksi existing, optimistic revision, lock, dan idempotency dipakai seluruh tindakan.

UI contract dibagikan kepada lane website: `fishPen` view menambah `unlocked/ready/fed`; action baru `stock_pen` (itemId reef_seruni,qty2), `feed_pen`, `harvest_pen`. Lokasi interaksi sah `(275,850)` di rakit kebun; pen visual merupakan kerja world berikutnya, bukan lantai baru di laut. Definisi memuat semua harga/durasi/kapasitas untuk UI tanpa hardcode.

Pemeriksaan sendiri: typecheck PASS dan7 API scenarios PASS pada DB UUID sendiri, memakai actual app/auth/transaction/routes. Mencakup migrasi, beli/tanam/rawat/tidur4hari/panen jahe, replay/stale revision, pen terlalu jauh, fragmen tidak bisa menjadi induk, actual net catch/extract/retry, story gate, pakan/replay/hari tanpa pakan, settlement ulang, cap5, panen/retry, serta konsumsi jahe/ikan atomik dalam shift kedai actual. Dua kegagalan fixture awal dicatat: posisi tepat di kasur adalah collider, sehingga diganti pendekatan legal yang dipakai uji rumah existing; kedai siklus2 perlu tiga temuan cerita existing, sehingga fixture melengkapinya. Tidak ada guard produksi yang dilonggarkan. Log `/tmp/jalasmara-overnight-breeding.log`, `/tmp/jalasmara-overnight-village-typecheck.log`.

Belum native/browser/perangkat fisik atau suite gabungan. Root mengoordinasikan slot; tidak ada import/Godot/browser dilakukan pada checkpoint ini.
