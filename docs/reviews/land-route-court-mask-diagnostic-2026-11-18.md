## Experiment and evidence

The existing `village-ground.ts` paints each route as separate 72-unit segment quads and octagonal joins, then clips those pieces around stone, houses, gardens and stairs. Previous width, tint, local grass-tongue and polygon-junction trials left orange strips, thin remnants and a hard V at the stair junction. This trial tested the opposite representation: one deterministic 480×280 authored-time soil mask, baked at five world units per pixel from the existing route graph and stair/court meeting points. The Godot grass shader sampled it on the existing upper and lower court floors; the old decorative dirt strips were skipped only for visual rendering. No route, floor, collider, server walkability or foot-contact data changed. The 92 KiB trial mask and its source generator were removed with the rejected code.

`npm run typecheck` passed. The focused `village-ground.test.ts` passed 6/6, including unchanged route clearance and walkability. The fresh worktree's first Godot editor import emitted transient missing font-cache errors; a second import completed without `SCRIPT ERROR` or `ERROR:`. Godot 4.7.2 Compatibility then rendered six fixed hub/forest frames at 667×375 and 844×390 with `TERRAIN FACETS RENDER PASS`, no render errors, one player and foot error no greater than 0.000061 world units. Hub debug counts stayed at 60 meshes and 78 map surfaces. This is native static evidence, not a WebGL or device performance claim.
