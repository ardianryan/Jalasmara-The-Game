# Reef 12 east-wall rear-depth trials — rejected

**Decision:** Neither candidate reaches the original-size visual bar. Both renderer edits were reverted; this branch contains only this report and four curated native captures. No source, shared world, collision, coral mounts, or boss targets change.

Base: main `8d1684eefa982642781629b78c6282cafb517b6a`. The seam belongs to the outer left boundary of `ReefRelief6`, which runs almost vertically at world x≈5500 between the upper wall and Reef 12 shelf. A previous polygon union failed because its z≈26 front face hid Nala at z=12, while the external vertical boundary remained. The new trials changed only the visual outline for terrain index 6 inside `TerrainGeometry.gd` and capped its left-side face behind Nala. The authoritative `world.terrainContours` remained untouched.

CPU polygon checks with Shapely 2.0.7 found the first 27-point visual outline and second 28-point outline valid and non-self-intersecting. Their extra visual overhangs beyond the server contour were about 21,072 and 124,073 world² respectively; that increasing overhang explains why the second wedge became so dominant. The first cap lowered visual depth from z=26 to z≈−32 near the swim lane; the second cap reached z≈−82 farther left. Native Godot 4.7.2 Compatibility (`ed1daf0bf`, Apple M2) rendered both `deep` and `deep_right` at 667×375 and 844×390 for each trial, with no script errors in the completed render logs. Both fixtures reported 43 coral pivots, 39 stone mounts, oxygen 77, and 700 coins; these mechanical assertions do not establish visual acceptance. The first cold editor import emitted missing-font cache messages, and the repeat editor import was clean. A missing local fixture on the first invocation of trial 2 was corrected before capture; that failed invocation produced no accepted image. No browser/device or integrated build pass is claimed for the reverted candidates.

**Design constraint for the next attempt:** Depth ordering can keep Nala visible, but moving the wall outline alone cannot make the open-water cavity look like a connected 2.5D reef. The next design must compose a limestone rear wall, shelf, and cave opening as one authored scene with multiple connected strata and deliberately placed negative space; avoid both a pasted vertical strip and a single diagonal boundary. Keep every added face behind the swim lane, show the same material continuing into the existing right wall, and review both cameras at actual sizes before changing collision. A renderer-only false-solid overhang must remain clearly decorative.

The screenshots are development proof, not game assets.
