# Dock plank joints — source candidate, 15 November 2026

The owner wants the coastal world to read as deliberately authored pixel art at the game viewport, rather than blurred or grid-like. This isolated candidate changes only `LandMaterials.gd`'s existing dock material. It adds sparse, staggered end joints and a narrow edge highlight on the planks, and aligns the existing nail mark to those joints. The existing single shader pass, dock mesh, collision, palette, source texture, and gameplay are unchanged.

At 844×390 native Godot Compatibility size, the [baseline](../visual/dock-joints-baseline-844x390-20261115.png) (`04e2d992ced4dc7e99de5d9c9bb0afec0f817198ec347b41c88a3eb4c9f09f86`) has long uninterrupted plank strips. The [candidate](../visual/dock-joints-candidate-844x390-20261115.png) (`ff7bc7a4e60e5175fcc26d775de5811b0423291a896750a2f9ecaeda2460bd1a`) gives them readable, subtle board ends. An earlier 96-unit/strong-contrast attempt made the deck resemble a regular grid and was discarded. The accepted trial uses 156-unit staggered lengths with lower contrast. Both captures use the same scene, camera, world map and 10:00 visual clock; these are native stills, not public browser or physical-device proofs.

The candidate render fixture passed and `git diff --check` passed. A first fresh-worktree editor import emitted temporary missing font-cache errors; the subsequent native render succeeded and produced the expected dock material. A clean second import and combined project checks remain required before integration. No third-party tool, asset or dependency was introduced; the material is project-authored and uses the existing project-art license. This source is not yet on `main` or staging, and full moodboard parity remains open.
