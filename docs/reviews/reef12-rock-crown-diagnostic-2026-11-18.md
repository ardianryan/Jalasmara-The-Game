# Reef 12 rock-crown diagnostic — 18 November 2026

Status: **rejected visual experiment; documentation only**. Source base `659dfdf` remains unchanged. The existing Reef 12 shared 26-point contour removes the earlier black slab, but its right surface still reads as a long, nearly level shelf in the native deep-ocean composition.

I trialed four small, low-poly rock crowns at x≈5080, 5390, 5720 and 6020. Each eight-facet crown used the existing porous-limestone material and placed its base vertices inside `WORLD.terrainContours[12]`, leaving server swim collision, the waste valve, coral mounts and six boss targets untouched. The first elevations were 72–92 world units above the reef front; a second render raised them to 154–174. Both treatments were visually imperceptible at actual 667×375 and 844×390 game sizes. They did not break the right shelf's horizontal reading, so the runtime source was restored rather than committed.

The focused `reef-sanctuary-contour.test.ts` passed under the repository's `tsx` runner. A first direct `node --test` invocation failed because Node did not resolve the repository's `.js`-to-TypeScript import convention; rerunning with `tsx` passed. Godot 4.7.2 Compatibility editor import exited 0 but logged transient missing font-cache/theme `ERROR:` messages while rebuilding a fresh worktree's imported resources. Both subsequent native `coral-rock-render.gd` trial runs passed in about 8–9 seconds each, produced shallow and deep frames at both sizes, and logged no `SCRIPT ERROR` or `ERROR:`. Resources remained oxygen 77 and coins 700; coral placement remained 43 pivots and 39 stone mounts. This is native Apple M2 still-frame evidence, not a Windows/Samsung S23 performance measurement.

Next work should change the **shared visual and collision silhouette** over a meaningful portion of the right shelf, but only with the valve approach and boss target routes tested. Repeating small surface decorations or tint adjustments will not address the long horizontal contour. A candidate must pass both native sizes, moving-browser review and the collision tests before it can be called an improvement. No external tool or moodboard art entered this trial; only project-owned Godot geometry, rock atlas, Node/TypeScript and Git worktree were used.
