# Nala requested-facing audit refinement

This is a CPU-only audit refinement for the isolated lower-body pilot. It changes no production gait, character artwork, controller, threshold or default activation.

The recorded `pose.desiredDirection` is CharacterVisual's intermediate artwork direction. In the preserved combined dock reversal, it advances NORTH_WEST→WEST→SOUTH_WEST while `source.requestedDirection` already requests SOUTH_EAST throughout movement. Comparing body and shoes only with that intermediate artwork could hide an upstream CharacterVisual lag even when all three match each other.

The checker now compares actual body and both shoe views with `source.requestedDirection` whenever it is recorded. Older observations fall back explicitly to the intermediate artwork target for descriptive metrics; any missing movement-request field marks raw-request recovery insufficient, so that fallback cannot establish acceptance. Declared initial setup observations are exempt from a movement-request requirement, but every case must contain actual requested-direction observations. It separately retains the artwork directions and count of observations containing a real requested direction. Continuous mismatch intervals are not erased when either intermediate source view or requested target changes. Paused time, missing cases, incomplete observations, terminal mismatches and original rejection remain explicit.
