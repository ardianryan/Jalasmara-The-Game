# Phase 1 close-pose articulation and pier grounding — candidate

This isolated package addresses two visible Phase 1 cutscene failures. In the prologue teaching shot, Ki Lurah's feet previously sat beyond the painted harbor pier, so the enlarged actor appeared to float above water. In the garden crisis, Gito's sling and marbles launched near the resting hand while his body scarcely acted. The candidate keeps the harbor establishing shot, moves Ki Lurah and three children onto the existing painted pier, and gives Ki Lurah a source-pixel pointing variant. Gito gets a raised, shoulder-connected forearm; the sling and marbles now start at that hand. No new deck or collision surface is invented.

The two generated transparent poses come from project-owned art, edited at source-pixel coordinates by `client-godot/resources/art/cinematics-v2/close-pose/build_gesture_poses.py` using Pillow 11.3.0. They are 128×128 and 96×128. The base and output SHA-256 hashes, source crops, rebuild command and license are in the adjacent art README and `docs/assets/provenance.md`. No moodboard art or external sprite is bundled. Godot 4.7.2 Compatibility and local `cwebp` 1.6.0 produced the evidence; WebP conversion is lossless at the original capture dimensions.

Original-size native A/B stills were inspected at 667×375 and 844×390. The focused Godot fixture `scripts/tests/cutscene-articulated-poses.gd` checks title/dialogue clearance at both physical sizes and can save all twelve sample frames with `CINEMATIC_CAPTURE=1`. A clean headless run with Godot 4.7.2 returned `CUTSCENE ARTICULATED POSES PASS: 0 captures`; the native capture run saved twelve images. Neither log showed `SCRIPT ERROR` or `ERROR:`. `git diff --check` passed. This is native renderer evidence, not browser or physical-device motion/performance evidence. The pointing finger remains subtle at actual size, and a whole-silhouette lean plus one pose swap is not full articulated teaching. The rest of Phase 1 cutscenes, gameplay NPC movement, and staged delivery remain outside this package.
