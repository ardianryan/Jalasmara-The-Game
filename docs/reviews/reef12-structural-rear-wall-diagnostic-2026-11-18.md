# Reef 12 recessed rear-wall trial — rejected

**Decision:** This trial improves one 667×375 frame but introduces obvious hard edges at 844×390. The runtime edit was reverted. This package contains only this report and six original-size, lossless WebP captures; it is not a visual parity or staging claim.

The isolated branch `work/reef12-structural-20261118` started at `203e028`. `TerrainGeometry.gd` temporarily built one additional project-atlas limestone face behind the swimmer, covering x5000–5640/y2440–2875 at depth −90. Its lower edge folded behind Reef 12's existing shelf. The aim was to fill the open blue upper-left void at the join to `ReefRelief6` without changing the collision-bearing `WORLD.terrainContours`, Nala, coral mounts, valve, or six boss resonances. Shapely 2.0.7 found the 12-point visual polygon valid and non-self-intersecting, area 246,320 world². This CPU result does not establish a good composition.

The two new edges are the same left boundary of the trial face seen by different cameras. Balanced rendering projects the 500-world-unit gap from the old x≈5500 seam to the new x=5000 edge to about 364 screen pixels at 844×390. Thus the trial moves a straight boundary rather than resolving it. The underwater composition should retain open water and an eroded rock entrance; simply filling the whole cavity with one opaque face is insufficient. A future candidate needs a naturally tapered/porous entrance whose transition is reviewed **in both `deep` and `deep_right` cameras at both sizes**, plus swim-lane depth ordering and a pass through the intervening camera positions. Do not widen the authoritative terrain or create a false solid shelf merely to hide the seam.

Godot 4.7.2 Compatibility (`ed1daf0bf`, Apple M2) used a local copy of `coral-rock-render.gd` with the additional `deep_right` camera `(5500,2800)`. The baseline run exited 0. The candidate's combined run wrote three 667×375 frames but stalled before its 844×390 capture; it was interrupted, and a separate 844-only native run exited 0 and wrote both required deep frames. The completed runs reported 43 coral pivots, 39 stone mounts, oxygen 77 and 700 coins. The first cold editor import logged missing font-cache resources; a second import exited 0 without `SCRIPT ERROR`, `ERROR:` or parse error. `git diff --check` passed before the source was reverted. Native stills do not prove browser motion or physical Windows/Samsung S23 performance.

The six proof images total about 1.3 MiB and were converted losslessly using local `cwebp 1.6.0`. They are development documentation from project assets, not new game assets.
