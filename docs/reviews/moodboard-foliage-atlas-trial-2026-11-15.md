# Foliage pixel-grid trial — rejected

The owner asked for the world to match the colorful, legible pixel-art moodboard. I tested whether reducing the existing canopy atlas would make its painted leaves clearer on the actual game screen. **This trial is not promoted to runtime.** At both reviewed screen sizes, the result was almost indistinguishable from the current foliage and did not materially improve the environment.

The original project atlas `client-godot/resources/art/land-foliage-v1.png` is 1536×1024 (six 512×512 cells), 2,363,421 bytes, SHA-256 `1f07437f9ff5f9cbc063c191904eecf734ffad859b3daf6f0fccf177c8aa4564`, introduced in source commit `ed70cad`. A local Pillow 11.3.0 script read that exact Git blob and reduced each cell independently to 96×96, discarded source alpha below 180, used box reduction, 36 colors without dithering and binary target alpha. The candidate was 288×192, 57,639 bytes, SHA-256 `73dbd057cb39724a4c10f90bd3ccabac5f7dbe2c23825ca88da81e882bbc364a`. It used only the project's source art. Pillow is an existing offline authoring dependency (MIT-CMU); no moodboard or third-party sprite was copied.

The CPU atlas check passed: six isolated cells, fully transparent/opaque alpha and at most 36 colors per cell. A Godot 4.7.2 Compatibility native render on Apple M2 loaded the real forest map and compared the original and candidate through the same 136 atlas Sprite3D instances without changing mesh count (24). The [667×375 side-by-side capture](../visual/foliage-atlas-trial-rejected-20261115.png) preserves each actual-size frame without upscaling. Separate 844×390 frames were reviewed locally. Only **0.096%** of pixels at 844×390 and **0.120%** at 667×375 differed by more than 16 in any RGB channel. No green halo or broken frame mapping was seen, but the foliage did not become clearly more readable or more faithful to the moodboard. The first fresh-worktree Godot editor import logged missing-font cache errors before completing reimport; the subsequent native render logged no `SCRIPT ERROR` or `ERROR`. This is native Mac evidence, not browser or physical Windows/S23 acceptance.

The production atlas, importer, renderer and tests were restored unchanged. The experiment's local script and raw captures remain only in ignored worktree paths; this commit adds the review and curated image. A future foliage pass should change authored leaf shapes, canopy layering and silhouette at target display size instead of relying on whole-atlas quantization. It should still preserve occlusion and mobile frame budget. No push or staging activation was performed.
