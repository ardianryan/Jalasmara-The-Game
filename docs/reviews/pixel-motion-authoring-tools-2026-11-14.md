# Pixel motion authoring tools — 14 November 2026

The owner directed that character motion be authored pixel by pixel or with controlled code, not accepted from a one-shot generated sprite sheet. Three repository references were reviewed for this workflow. This review does not change the game runtime or claim any new character animation.

| Tool | Finding | Decision |
| --- | --- | --- |
| [PixelHand](https://github.com/SirLichDevCraft/PixelHand) | MIT, dependency-free Node authoring API/CLI/MCP; palette-indexed editable grids, authored rigs, planted contacts, eight facings and frame review. Upstream `0.2.0-rc.1` at `e14af5884bd1a7ceaac33f8725c1a25dcd2cfbdb`. | Installed in ignored `.runtime/tools/pixelhand` for **offline authoring**; tracked wrapper, pin and license in `tools/pixelhand/`. `npm test` passed: 27 smoke tests, integration suite, 24 production tests. No exported sprite is accepted or bundled yet. |
| [SpookyGhost](https://github.com/SpookyGhost2D/SpookyGhost) | MIT nCine-based procedural sprite-animation editor. Can help pose/loop exploration, but brings a separate native C++/nCine authoring stack. Upstream HEAD reviewed: `187a90dd42cf775f850f3aaca2fec995cd488dbb`. | Keep as a reference. Do not add a second live animation runtime or build stack before a bounded source-art pilot proves it improves the existing Godot pipeline. |
| [Crivo / Pixel-Art-Matrix-Editor](https://github.com/ravelroot/Pixel-Art-Matrix-Editor) | Pixel editor with RGBA layers, frame-by-frame cels, `.ase`/PNG/sprite-sheet export. The repository's custom license permits using the editor and commercial use of art made with it, but forbids modifying, copying source into another project or redistributing the software without written authorization. Upstream HEAD reviewed: `6b461beec86dcf6ab6d7e276bf0cd6a555ca6dc1`. | External editor reference only. Do **not** vendor, fork into WorldKit, or adapt its code. |

For the next Nala/NPC pilot, first choose one existing source pose and one movement defect, then author four or eight controlled frames. Compare planted-foot drift, limb continuity, opposite facings, palette count, atlas bytes, Godot import size, and actual 667×375 playback. Keep editable pixel source and PNG/contact sheet under project provenance. PixelHand's mechanical checks supplement visual review; they do not certify natural gait by themselves. Shipping any result requires the normal Godot/world/browser checks and owner device review. Cinetic remains a separate offline film tool, not a character-motion runtime.

The three upstream repositories were examined through their README and license files on 14 November 2026. Only PixelHand was cloned and tested. No source, image, or runtime dependency from SpookyGhost or Crivo was copied into Jalasmara.
