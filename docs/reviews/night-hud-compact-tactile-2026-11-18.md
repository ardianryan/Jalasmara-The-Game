# Compact tactile night notice

The 667×375 Kedai HUD audit showed a temporary notice covering about 81 physical pixels beneath the utility and weather badges. It repeated the Mbah Wira instruction already shown beside the action button. The notice now uses 14 px physical-equivalent type on short landscape land screens, a slim wood and brass pixel frame with a sharp shadow, and a roughly 40 px minimum height for the short sentence. When the current action prompt names the same target, the notice keeps its first sentence on screen and retains the full message for later layout changes. Dive and larger-screen notice sizing is unchanged. Dialogue and modal state still hide the notice.

The source is `client-godot/scripts/GameHud.gd`; the focused fixture is `scripts/tests/hud-dialogue-night-audit.gd`. No new art, shader, font, dependency, or license was introduced. Godot 4.7.2 Compatibility rendered the native 667×375 and 844×390 component fixtures after a fresh worktree import. Both final focused native and headless runs passed without `SCRIPT ERROR` or `ERROR:`. A transient test-only global `GameHud` reference caused a compile failure on the first final rerun; that assertion was removed and both runs passed again. The initial import also printed missing-font errors while its fresh cache was being populated; the completed import and subsequent checks loaded the fonts normally. The source and project-owned background were rendered as a component fixture; this does not prove actual Kedai service, moving camera, or physical-device frame pacing.

The accepted visual comparison is [667×375 before](../visual/hud-dialogue-night-audit-20261118/gameplay-667x375.png) to [667×375 after](../visual/night-hud-compact-20261118/gameplay-667x375.png), with [844×390 after](../visual/night-hud-compact-20261118/gameplay-844x390.png). The smaller notice leaves the play corridor more open, keeps the action button and full target prompt readable, and retains the tactile border. The separate “Bicara dengan Mbah Wira” action prompt remains a large flat dark strip at 844×390; the entire top-right cluster is still dense. Actual night service must be reviewed on Windows and Samsung S23 before calling the HUD fully equivalent to the moodboard.
