# Gito gait correction — 15 November 2026

The owner showed Gito walking awkwardly on the village dock. The production child uses `ResidentArtRig3D`, not the older voxel fallback. His contact planner already scales stride to the source leg length, but the rig's three-dimensional knee solver bent chiefly sideways in billboard space. That gave a small child a splayed or crossed-knee silhouette even while the measured soles remained planted.

`ResidentArtRig3D.gd` now biases knee bend toward the body's depth axis, retaining a small part-specific lateral component. It also gives the two arms a more legible alternating swing during ordinary motion. Source pixels, body scale, contact positions, fixed limb lengths, route, collision, schedule and gameplay state are unchanged. Reduced-motion mode keeps its existing restrained arm behavior.

The focused rig test now asserts that Gito's knee bend is deeper than its sideways displacement while he walks. Its opt-in native capture records six frames on open terrain, so the legs are visible rather than hidden by foliage. The curated [six-frame sheet](../visual/gito-gait-native-20261115.png) is a 96 KiB crop of real Godot Compatibility render output, SHA-256 `6fd897b79cbda0b2b5c8fdfd12d3d64dfca1133f1850b964d2807795b547d893`. The raw frames were inspected before curating this sheet. This is native Apple M2 evidence, not a browser or Samsung/Windows capture.

Validation: Godot focused headless and native both passed 576 articulated poses; the full `npm run check:world` passed, including 11,826 actual resident-commute poses, planted soles on rendered geometry, fixed bone lengths, pause and route continuity. `npm run typecheck` and `npm run build` passed. A first `npm test` attempt without database services failed on connection timeouts. The fixture-backed rerun passed **123/123** against a dedicated MongoDB replica set on port 27019 and Redis on port 6381. Both services were stopped and the owned temporary MongoDB directory (4,820 KiB) was removed; no persistent or owner data was used.

No new generated asset or third-party tool was used. The existing project portrait/cutout and Godot 4.7.2 renderer were used; Pillow only cropped the native evidence sheet. Children still have one authored three-quarter view. A full side/rear turn cannot be claimed from this gait correction; review live motion on Windows and Samsung S23 before calling that work complete.
