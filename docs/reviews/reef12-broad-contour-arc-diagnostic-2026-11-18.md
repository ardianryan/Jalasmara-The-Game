# Reef 12 shared contour trial — 18 November 2026

Status: **rejected after native visual review; documentation only**. Isolated branch `work/reef12-contour-arc-20261118` started from `e22b462`. No runtime, collision, test, asset, or shared-world source change is recommended for integration.

The accepted 26-point `WORLD.terrainContours[12]` still presents a long right shelf in the [667×375](../visual/reef12-volume-20261118/deep-667x375.png) and [844×390](../visual/reef12-volume-20261118/deep-844x390.png) deep-ocean views. I tested two authored replacements in `packages/shared/src/world.ts`, so the same polygon governed the server swim boundary and the Godot rock volume. A focused `reef-sanctuary-contour.test.ts` variant checked non-crossing edges, reachability of all six boss targets, and a 40-unit grid route to the waste-valve approach. It passed for both variants. The valve at `(4660,2630)` remained outside the solid.

The first variant carved two broad coves in the right shoulder and extended its lower edge to keep rock thickness. Its [native 667×375 frame](../visual/reef12-contour-trial-20261118/rejected-carve-667x375.png) replaced the old shelf with a **longer straight underside**; the result looked more rectangular. The second variant kept the old lower edge and raised a wide crest over x≈5220–5860. Its [667×375](../visual/reef12-contour-trial-20261118/rejected-crest-667x375.png) and [844×390](../visual/reef12-contour-trial-20261118/rejected-crest-844x390.png) native frames still read as the same nearly level shelf at actual game size. Neither met the visual acceptance bar. Source and temporary test changes were restored before commit.

Godot 4.7.2 Compatibility on Apple M2 rendered shallow and deep views at both sizes for each variant. Both native runs printed `CORAL ROCK RENDER PASS`, kept oxygen 77 and coins 700, and logged no `SCRIPT ERROR` or `ERROR:`. The first fresh-worktree editor import had transient font-cache errors; a second import was clean before rendering. `tsx --test apps/api/test/reef-sanctuary-contour.test.ts` passed for both variants. This is CPU/native still-frame evidence, not browser, physical-device, motion, or full art-parity proof.

The failed trials show that broad XY variation alone does not solve the full-width rock-face reading: the current 3D terrace/profile and its low-contrast material continue to emphasize horizontal bands. The next package should inspect the silhouette together with the projected terrace face and coral anchoring, author a cohesive shape rather than isolated crests, and preserve the shared collision/navigation contract. No external tool or moodboard image was used; this trial used project-owned Godot geometry, the existing rock atlas, Node/TypeScript, and Git worktree isolation.
